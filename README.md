# astrbot_plugin_random_pic

AstrBot 随机抽图插件。图片按两个维度划分：

- **风格**：二次元 / 三次元（Cosplay 与真人写真）
- **分级**：擦边 / R18（群聊、私聊分别控制是否允许 R18，默认都不允许）

二次元来自 [Danbooru](#danbooru)（按用户投票分筛选的高分插画）；三次元从 E-Hentai / ExHentai、[哔咔](#哔咔)、[CosplayTele](#cosplaytele)、[NudeCosplay](#nudecosplay)、[XiuRen](#xiuren)、[PixiBB](#pixibb) 和 [禁漫天堂](#禁漫天堂) 中按比例选（默认均分）。每个站点都可以在「图源管理」里单独开关、限定只用于擦边或 R18。不带关键词就是在整个池子里完全随机。

一次抽卡抽若干个**图集**，每个图集是同一个画廊 / 帖子 / 本子里的几张图。每个图集第一张图上方有两行标题，后面的图上方只有页码：

```
【2】某某写真
第 15/42 张 · E-Hentai
[图]
第 31/42 张
[图]
作者：…
画廊：https://e-hentai.org/g/…
```

即这次抽卡的第 2 个图集，来自 E-Hentai（来源还有 ExHentai、哔咔、CosplayTele、NudeCosplay、XiuRen、PixiBB、禁漫天堂），两张图是该作品 42 张里的第 15、31 张，最后是说明文字。标题行和说明文字都可以关闭。

## 指令

```
/抽图 [风格] [分级] [关键词...] [图集数 或 图集数x每集张数]
/抽图 全集 [风格] [分级] [关键词...]   直接随机抽一个完整作品（写 pdf 则打包成 PDF）
/随机角色 [同上]
/全集 [序号]          回复抽到的图片，获取整个作品（默认合并转发）
/pdf [序号]           同上，打包成 PDF
/全集 <作品链接>      /pdf <作品链接> 同理
/抽图 帮助            回复用法说明（任何指令后面跟「帮助」或 help 都可以）
```

| 参数 | 可选值 | 不写时 |
|---|---|---|
| 风格 | `二次元` / `三次元` | 「抽图指令 › 默认风格」（三次元） |
| 分级 | `擦边` / `r18`（也接受 `R18`、`色图`） | 「默认分级」（擦边） |
| 数量 | `3`（3 个图集）或 `3x4`（3 个图集、每集 4 张，也可写 `3*4`、`3×4`） | 「默认图集数」×「每个图集的张数」（1 × 1） |
| 完整作品 | `全集`（按「完整作品 › /全集 的发送方式」发送）、`pdf`（打包成 PDF） | 不抽完整作品 |
| 关键词 | 其余所有词 | 无 |

- 参数顺序随意。总张数不超过「单次最多张数」（默认 5）：超出时先减每集张数，再减图集数。
- 关键词可以直接写中文：标签库能识别的中文名（角色、作品、Coser、属性等）会翻译成 E-Hentai 标签，例如 `芙莉莲` → `character:"frieren$"`、`兔女郎` → `female:"bunny girl$"`；前面加 `-` 表示排除。查不到的词和已经写好的 E-Hentai 语法原样搜索。同一个中文名对应多个标签时（约 600 个，例如 `胡桃`）按 角色 → 作品 → Coser → 属性 → 画师 → 社团 的顺序取第一个，不对时直接写标签，例如 `character:"hu tao$"`。
- 二次元的关键词由 Danbooru 补全成标签（它的 wiki 收录了大量中文、日文名，例如 `芙莉莲` → `frieren`、`原神` → `genshin_impact`、`兔女郎` → `playboy_bunny`），补全不到的中文名再经标签库翻译成英文名补全；最多 2 个关键词（`/随机角色` 时 1 个），`-` 开头的排除词不限个数。二次元一张图就是一个图集，`3x4` 这类写法只取图集数。
- `/随机角色` 的每个图集先随机抽一个角色，再在该角色的作品里抽：每个角色的概率相同，冷门角色也会出现。二次元从 Danbooru 帖子数最多的 2000 个角色里抽（带关键词时从和关键词相关的角色里抽，例如 `/随机角色 二次元 原神`）；三次元从标签库约 9,900 个角色中抽、只用 E-Hentai。没有作品的角色会换一个，每个图集最多换 10 个，所以会慢一些。
- 别名（「启用别名」）：`/二次元`、`/三次元`（分级用默认值），`/擦边`、`/色图`（风格用默认值），后面同样可以跟参数。
- 群聊里不带 `/`、也不 @ 机器人，直接发 `抽图`、`抽图 原神 2`、`全集` 等也能触发（「群聊不带 / 也能触发」）。指令词必须在消息开头，后面只能跟空格和参数，「二次元真好」这类普通聊天不会触发。
- 帮助不抽图、不占冷却。没有单独注册 `/help`，因为它是 AstrBot 自带的指令。

示例：

```
/抽图
/抽图 二次元 3
/抽图 原神 2x3
/抽图 二次元 芙莉莲 -兔女郎
/抽图 全集 原神
/抽图 pdf r18                      （需允许 R18）
/抽图 r18 character:"hu tao$"
/随机角色 二次元
```

## 图集与发送

- 每个图集独立选图源，从一个作品里抽「每个图集的张数」页，**按页码从小到大**发送；某页下载失败时换同一作品里的其他页补上（最多多试同样多页，至少 2 页），作品页数不够或补不上时这个图集少几张。图片下载遇到连接失败（例如代理重置连接）会等 1 秒重试一次。各图集之间的顺序是随机的；没抽够图集数时最后提示「仅获取到 x/y 个图集」。
- 「取图位置」：`随机页`（默认）在作品中随机抽页；`从第一页起` 取开头几页（每集 1 张时就是封面）。R18 作品通常从穿着完整开始，随机抽页时跳过开头 30%。

「发送方式」决定怎么发：

| 方式 | 说明 |
|---|---|
| 合并转发（默认） | 一条合并转发消息，**每个图集一个节点**，节点顺序就是序号。只在 QQ / OneBot 可用，其他平台、或只有一个图集时改为图文混合。 |
| 图文混合 | 各图集依次排在一条普通消息里；每条最多 10 张图，更多时分几条发，超过 10 张的图集拆开，后一段重新带上完整标题。 |
| 逐条发送 | 每张图一条消息，都带完整标题；说明文字跟在图集最后一张后面。 |

QQ 拒发（NapCat 发送接口报错，常见于群聊里裸露较多的图）时不交给 AstrBot 原样重发，而是回复一句「发送失败：QQ 拒发了这条消息」；在群里被拒时建议私聊重新抽图。

**并发**：一次抽多个图集时各图源同时抽取，每个图源内部最多同时处理 4 个图集，图集里的几张图也并发下载；其他三次元图源没抽够的图集在它们结束时马上由 E-Hentai 补。Danbooru 的接口请求按每秒约 6 次限速，E-Hentai 的页面请求间隔 0.5 秒（过快会被临时封 IP），抽卡耗时主要受它限制。

## 完整作品（/全集、/pdf）

回复抽到的图片发送 `/全集` 或 `/pdf`，插件下载这个图集所在的整个作品发送：`/全集` 按「完整作品 › /全集 的发送方式」发送（默认合并转发），`/pdf` 打包成 PDF。`/抽图 全集`、`/抽图 pdf` 则直接随机抽一个完整作品发送，其他参数（风格、分级、关键词）照常写；抽到的作品被过滤、分级不符或超过页数上限时重抽，最多 3 次。所有图源都支持：

| 图源 | 整个作品是 | 链接 |
|---|---|---|
| E-Hentai / ExHentai | 整个画廊 | `https://e-hentai.org/g/123/abcdef0123/` |
| CosplayTele、NudeCosplay、XiuRen、PixiBB | 整个帖子（一套写真，通常 30~150 张） | `https://cosplaytele.com/hiyuki-2/`、`https://xiuren.biz/xxx/`、`https://sexy.pixibb.com/xxx/`（PixiBB 的各个子域名都认） |
| 哔咔 | 整本，所有话按顺序连起来 | 没有公开链接，只能回复抽图发出的消息 |
| 禁漫天堂 | 整本，所有章节按顺序连起来 | `https://18comic.vip/album/123456`（域名里带 `18comic` 或 `jm` 的都认） |
| Danbooru | 这个帖子和它的差分（父帖子、子帖子），按发布顺序 | `https://danbooru.donmai.us/posts/123` |

找作品的顺序：

1. 参数里的作品链接，例如 `/全集 https://e-hentai.org/g/123/abcdef0123/`、`/pdf https://cosplaytele.com/hiyuki-2/`。
2. 回复的消息。QQ（OneBot）上插件自己调用发送接口，记下每条发出消息的 ID 和其中的图集（包括图源和作品 id），回复时按消息 ID 直接查（NapCat 发出的合并转发读回来是一张卡片，读不到内容，所以不依赖消息内容）。查不到时（AstrBot 代发、其他平台）解析被回复消息的文字：按 `【序号】` 标题行分段，在说明文字里找作品链接（哔咔没有链接，这种情况下获取不了）。**回复的消息里有多个图集时必须带序号**，即 `【】` 里的数字，例如 `/全集 2`；不带时插件列出每个图集的序号和标题。
3. 不回复任何消息时，用本会话上一次抽卡（能获取的图集都来自同一个作品时可以不带序号）。

- **合并转发**：每张图一个节点，一条合并转发最多 100 个节点，超过 100 张时拆成多条依次发送；每条的第一张图带完整标题，说明文字跟在最后一张后面。只在 QQ 上可用，其他平台改发 PDF。发出的合并转发也会登记，回复它可以再 `/pdf`。
- **PDF**：超过 200 页时分成多个 PDF 依次发送，文件名标出页码范围，例如 `标题 (1-200).pdf`。每页转成质量 85 的 JPEG（原图是 JPEG 且转换后不会更小时保留原图，透明背景铺白，动图取第一帧）；抽图发送的图片始终是原图。打包过的作品再次请求时直接复用（分卷齐全才复用），最多保留 10 个作品的 PDF，只清理本插件生成的文件（文件名是 `ehentai_123`、`xiuren_123`、`pica_5f1a…` 这样的「图源_作品 id」）。有页面下载失败时会提示缺了几页，这样的文件不会被复用。
- 发送前先发一条说明：标题、来源、分级、页数和发送方式。
- **页数上限**：超过「完整作品 › 最大页数」（默认 500 页）的作品不获取，提示作品的页数；随机抽完整作品时抽到这样的作品就重抽。有的 AI 作品上万页，下载和打包都要很久。
- 分级闸门与抽图相同：E-Hentai 按画廊的分类和标签、哔咔按「無H內容」标签、CosplayTele、NudeCosplay 按站点分类判定分级，禁漫天堂按「无H」「无漏」一类标签，XiuRen 为擦边，PixiBB 和无法判定的按 R18 处理；R18 作品只能在允许 R18 的会话发送。命中黑名单、带重口标签、没有标签（E-Hentai、哔咔）、属于站点排除的分类 / 标签（PixiBB 的街拍、福利姬订阅；开启「屏蔽 AI 作品」时各站的 AI 分类）、带禁漫排除标签的作品不予发送。
- Danbooru 的差分逐张过滤（黑名单、排除的标签、多为儿童设定的角色、动图），过滤掉的不发送；剩下的有任何一张是 q、e 时整组按 R18。
- E-Hentai 每页都要单独请求、受请求间隔限制，页数越多越慢，也越消耗图片额度；其他图源一次拿到全部图片地址，只花下载时间（实测 111 张的 CosplayTele 帖子约 3 秒）。
- 请求自动排队，不需要重试：最多同时下载 2 个完整作品；PDF 同一用户的请求依次进行，有人请求的作品正在打包时等它完成后一起发送。
- **QQ 机器人（NapCat 等）和 AstrBot 分属不同容器时，「PDF 存放目录」必须是两边路径相同的共享目录**（例如两边都挂载为 `/app/sharedFolder` 时填 `/app/sharedFolder/random_pic_pdf`），否则文件发不出去。
- 已发送图集的记录（最近 1000 条消息、每个会话最近一次抽卡）保存在插件数据目录的 `sent_albums.json`，重启后仍可用。

## 定时推送

通过 QQ（aiocqhttp / NapCat 适配器，自动查找）主动推送到指定的群和用户。在「定时推送 › 推送任务」里可以添加多条任务，每条有自己的推送目标、时间和内容：

| 任务类型 | 时间 |
|---|---|
| 按间隔推送 | 每天从「起始时间」（默认 00:00）起每隔「间隔」分钟推送一次，到次日的起始时间重新计算。例如两个间隔 360 分钟的任务，起始时间分别填 00:00 和 03:00，就是每 3 小时轮流推送。 |
| 按时间点推送 | 每天在列出的时间推送，例如 `08:00`、`20:00`。 |

- **推送群** / **推送 QQ**：群号、QQ 号列表；QQ 按私聊推送，通常要求对方是机器人的好友。都为空的任务不推送；关闭「允许在群聊使用」时推送群不生效。
- **推送内容**：写法同 `/抽图` 的参数，留空等于不带参数的 `/抽图`。例如 `二次元 3`、`原神 2x3`、`全集 原神`（推送一个完整作品）、`pdf r18`（推送一个 R18 完整作品的 PDF，需要该会话允许 R18）。
- **启用**：可以暂时停用某条任务而不删除它。
- 时间按 AstrBot 所在机器的时区；时间写错的会在日志里提示并忽略。
- 每次推送前先单独发一条说明，写明这是抽图插件几点的定时推送；完整作品还附带标题、来源、分级、页数和发送方式。
- 每个群、每个用户单独抽一次，同样会登记图集，回复推送的消息也能 `/全集`、`/pdf`。
- 推送不受群白名单、冷却和每日上限限制，但仍受 R18 开关约束（例如只允许私聊 R18 时，R18 内容只推送给 QQ，不推送到群）；被拒绝、抽图失败或发送失败时只记日志，不在会话里发消息。

「图源管理」里每个站点一组设置：

- **启用**：关闭后这个站点不参与抽图，`/全集`、`/pdf` 也不再获取它的作品（提示「已在图源管理里停用」）；关闭时其余设置收起。关闭 Danbooru 就不能抽二次元。
- **适用分级**：「通用」「仅擦边」「仅R18」，限定站点只在哪种分级的抽图里使用。站点自己只有一种分级的（XiuRen 只有擦边；PixiBB、禁漫天堂不区分裸露程度，只用于 R18）没有这一项——把它们放进另一种分级会破坏严格分级，所以不提供。
- **比例**：1~10 的滑块，默认都是 5，即均分。二次元只有 Danbooru，没有比例。
- 站点自己的门槛和账号：Danbooru 最低评分、E-Hentai 最低画廊评分和 cookie、哔咔手动账号、禁漫天堂最低点赞数和域名，见各图源的小节。

每个图集按比例从这次能用的图源里选一个：启用、适用分级包含这次的分级、而且能处理这次的关键词。不能用的图源不参与分配，它的份额由其余可用图源分掉。例如只开 E-Hentai、哔咔、CosplayTele 时，带 `cosplayer:"xxx$"` 哔咔不能用，由 E-Hentai 和 CosplayTele（取出标签名 `xxx` 搜索）分；`/随机角色` 只有 E-Hentai 能用；R18 时 XiuRen 不参与，擦边时 PixiBB 和禁漫天堂不参与。其他三次元图源没抽够的图集由 E-Hentai 补（E-Hentai 停用或适用分级不含这次的分级时不补）；二次元没抽够时不补。一个能用的图源都没有时回复「没有能抽三次元·R18的图源」一类的提示。关键词命中黑名单或屏蔽的重口、跨性别标签时，所有图源都直接拒绝（原词和翻译后的标签都检查）。

### Danbooru

[Danbooru](https://danbooru.donmai.us) 是标签最规范的二次元图站（多为 Pixiv、推特上的插画），匿名使用，不需要账号。插件只抽**用户投票分不低于 150**（「图源管理 › Danbooru › 最低评分」）的帖子，一个帖子（一张图）就是一个图集，发原图（超过 10 MB 时发 850px 宽的缩小图）。

- **分级**：Danbooru 的 sensitive 为擦边，questionable 和 explicit 为 R18。2026-10 抽样目检（150 分以上）：擦边 24 张随机图约 20 张明显擦边、其余较轻，全部是完成度高的插画；R18 全部达标（questionable 多为露点，explicit 为性内容）。50~100 分的擦边只有约 16/24，杂图也多，所以默认 150 分；此时擦边池约 7.8 万张、R18 池约 27 万张。带关键词或 `/随机角色` 时按这个分数搜不到，会降到三分之一（50 分）再搜一次。
- **排除**：漫画、多格、黑白、草图、3D、男同、男性向、兽人、视频、动图和 `aged_down`（低龄化版本），开启「屏蔽 AI 作品」时还排除 AI 生成和 AI 辅助；黑名单、重口标签与其他图源相同（Danbooru 标签的下划线视为空格）。

| 抽图指令 | 默认风格 / 分级、默认图集数、每个图集的张数、单次最多张数、取图位置、别名、群聊不带 / 也能触发 |
| 使用权限 | 允许在群聊使用（总开关）、群聊允许 R18、私聊允许 R18、管理员、群白名单、用户黑名单、每人冷却、每人每日张数上限 |
| 内容过滤 | 屏蔽重口作品、屏蔽跨性别作品、屏蔽 AI 作品、额外屏蔽的标签 |
| 发送 | 发送方式、显示标题和序号、附带作者、标签和链接 |
| 完整作品 | 启用 /全集、/pdf，/全集 的发送方式，最大页数，PDF 存放目录 |
| 图源管理 | HTTP 代理；8 个站点各一组：启用、适用分级、比例，以及站点自己的门槛和账号（见[图源](#图源)） |
| 定时推送 | 推送任务列表（按间隔 / 按时间点） |

- 权限的优先级：「允许在群聊使用」最高，关闭后插件不处理任何群聊消息（不回复、不提示，帮助也不响应，管理员也不例外），推送任务里的群也不再推送，只推送给私聊的 QQ；其次是**管理员**（QQ 号列表），在私聊和群聊里不受白名单、黑名单、R18 开关、冷却和每日上限限制；其余设置只约束普通用户。
- 国内通常需要配置 HTTP 代理，所有图源和标签库下载都走它。所有请求都有超时（20 秒），全部失败时回复失败原因，不会没有响应。
- 图片先下载到插件数据目录的 `cache`，再以本地文件原样发送；缓存超过 200 MB 时删除最旧的图片，10 分钟内下载的不删。单张超过 10 MB 的图片丢弃换一张。
- 冷却和每日计数（按成功发出的张数，完整作品按页数）保存在内存中，重启后清零。

## 标签中文库

中文关键词翻译、说明文字中的作品 / 角色中文名和三次元的 `/随机角色` 依赖 [EhTagTranslation 数据库](https://github.com/EhTagTranslation/Database)。插件运行时从 GitHub 下载 `db.text.json.gz`（约 1.3 MB，走代理）到插件数据目录，每 7 天更新一次；下载失败时沿用旧缓存，10 分钟内不重试。标签库不可用时关键词原样搜索（Danbooru 仍能补全中文名）、说明文字显示英文标签、三次元的 `/随机角色` 不可用。

数据库内容由 EhTagTranslation 的编辑者共同所有，按 [CC BY-NC-SA 3.0](https://github.com/EhTagTranslation/Database/blob/master/LICENSE.md) 提供，本插件不附带其数据。
